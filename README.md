# Heavy Revolver — аддон к Iron's Arms 'n Artifice (NeoForge 1.21.1)
Сборка: открой папку в IntelliJ IDEA (Java 21) или добавь gradle wrapper из NeoForge MDK, затем `./gradlew build`.
Jar появится в build/libs/.
Управление: ПКМ — выстрел, Shift+ПКМ — перезарядка.
Настройки урона/дальности — константы в HeavyRevolverItem.java.
